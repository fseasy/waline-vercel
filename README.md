# Waline 

这个是 waline-vercel 的部署。仓库代码很简单，主要是用了 npm https://www.npmjs.com/package/@waline/vercel 包。

如果要更新 waline 版本，只需修改 `package.json` 里的版本即可。最新版本可以直接去上面的 npm 仓库看。

对应的 vercel，在 https://vercel.com/fseasy-3189s-projects/waline-vercel.

绑定的域名： waline.fseasy.top

支持的服务：k.fseasy.top, blog.fseasy.top

## Deploy

这里提交更新，vercel 那边就会自动部署。

如果 vercel 那边想重新部署（比如版本里写的是 latest），就点击最新的部署，再点重新部署（没有项目维度的重新部署选项，找了半天）。
